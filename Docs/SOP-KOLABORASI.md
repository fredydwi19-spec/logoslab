SOP Kolaborasi Tim Pengembangan Game Logos Lab
1. Peran dan Tanggung Jawab

Ketua Tim: Penanggung jawab proyek yang berwenang menugaskan, mengaudit secara final, melakukan revisi bypass, dan mempublikasikan game ke landing page.

PIC Pembuat Game: Bertanggung jawab atas input materi edukasi (soal, kata, petunjuk), memastikan mekanik game berjalan, dan melakukan perbaikan berdasarkan revisi.

PIC Pakar: Bertanggung jawab meninjau kualitas konten (akademis/teologis), melakukan preview, dan memberikan persetujuan atau revisi.

2. Alur Status Proyek (State Management)

DRAFT: Proyek baru dibuat oleh Ketua Tim. Hanya Ketua Tim yang bisa mengedit informasi dasar di fase ini.

REVIEW_PAKAR: Proyek telah selesai dikerjakan oleh Pembuat Game dan dikirim ke Pakar untuk ditinjau.

REVISI_PAKAR: Proyek dikembalikan oleh Pakar ke Pembuat Game karena ditemukan kesalahan konten.

ACCEPT_PAKAR: Konten telah disetujui oleh Pakar dan diteruskan ke Ketua Tim untuk verifikasi akhir.

REVISI_KETUA: Proyek dikembalikan oleh Ketua Tim langsung ke Pembuat Game (Bypass Pakar) jika ditemukan ketidaksesuaian standar platform.

PUBLISHED: Proyek disetujui oleh Ketua Tim dan tampil di landing page untuk dimainkan publik.

3. Standar Visual & Teknis

Warna: Dominasi Deep Navy (#1A237E), Electric Gold (#FFC107), dan Vibrant Orange untuk elemen interaktif.

Aset: Semua proyek wajib menggunakan logo resmi dari path yang ditentukan.

Interaksi: Setiap transisi status wajib tercatat dalam sistem dan memberi notifikasi kepada PIC terkait.
